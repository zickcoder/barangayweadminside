7. Sequence Diagram — Full System Lifecycle (Login → Incident → Broadcast → Receive) UPDATED

sequenceDiagram
    autonumber
    actor Agency as Emergency Agency
    actor CallSys as Call Intake System
    participant CIM as CIM (Integration Bridge)
    participant AUTH as Supabase Auth
    participant DB as PostgreSQL DB
    participant RT as Realtime Engine
    actor Admin as Admin Web Portal
    actor Resident as Resident Mobile App

    Note over Admin,AUTH: Phase 1 — Authentication
    Admin->>CIM: POST /auth/v1/token (email + password)
    CIM->>AUTH: Validate Credentials
    AUTH-->>CIM: Return JWT Token
    CIM-->>Admin: Login Successful — Dashboard Loaded

    Resident->>CIM: POST /auth/v1/signup or token
    CIM->>AUTH: Create or Verify Resident Account
    AUTH-->>Resident: Auth Token — App Unlocked

    Note over Agency,DB: Phase 2 — Incident Intake via CIM
    Agency->>CIM: POST /api/incoming-incidents (JSON payload)
    CIM->>CIM: Normalize & Validate Payload
    CIM->>DB: INSERT incident — Status: Pending
    DB-->>RT: CDC Change Event Fired
    RT-->>Admin: Realtime push — New Pending Incident

    Note over CallSys,DB: Phase 3 — Emergency Call Intake (Hotline)
    CallSys->>CIM: POST /api/emergency-call-intake
    CIM->>CIM: Validate Hotline Payload
    CIM->>DB: INSERT into emergency_hotlines
    DB-->>RT: Hotline Table Changed
    RT-->>Admin: Hotline Manager Refreshed
    RT-->>Resident: Hotlines Display Updated

    Note over Admin,Resident: Phase 4 — AI Summarize & Broadcast
    Admin->>CIM: Request AI Summarization (incident description)
    CIM->>CIM: Forward to Gemini 3.5 Flash
    CIM-->>Admin: Return AI Alert Summary Text
    Admin->>DB: INSERT into alerts + UPDATE incident Status: Broadcasted
    DB-->>RT: Alert CDC Event Triggered
    RT-->>Resident: WebSocket Push — Emergency Alert Delivered

8. Emergency Call Intake — Custom Hotline Integration Flowchart NEW

flowchart TD
    START(["📞 Emergency Call Intake Subsystem\nExternal Hotline System Initiates Request"])

    START --> POST["HTTP POST /api/emergency-call-intake\nPayload: name, phone_number, category,\nsource_system, priority, description"]

    POST --> CIM_RECV["📡 Communication Integration Module\nReceives & Validates Payload"]

    CIM_RECV --> VALID{"All Required Fields\nPresent & Valid?"}

    VALID -- No --> ERROR["Return 400 Bad Request\nError Message to Call Intake System"]
    ERROR --> END_ERR(["❌ Hotline Entry Rejected"])

    VALID -- Yes --> NORMALIZE["CIM Normalizes Payload\nSets: is_local=true, status=ACTIVE\nsource=call-intake"]

    NORMALIZE --> RLS_CHECK{"Row Level Security\nPolicy Allows INSERT?"}

    RLS_CHECK -- No --> RLS_ERR["Return 403 Forbidden\n(API Key or RLS Policy Failed)"]
    RLS_ERR --> END_RLS(["❌ Rejected by Security Layer"])

    RLS_CHECK -- Yes --> INSERT["INSERT into emergency_hotlines\n{id UUID, name, phone_number, category,\nis_local, source_system, priority, status}"]

    INSERT --> DB_DONE["✅ Hotline Saved to PostgreSQL Database"]

    DB_DONE --> CDC["Supabase Realtime CDC\nFires Change Event on emergency_hotlines"]

    CDC --> ADMIN_RT["Admin Web Portal Receives\nRealtime Update"]
    CDC --> APP_RT["Resident Mobile App\nHotlines Display Refreshed"]

    ADMIN_RT --> ADMIN_VIEW["Hotline Now Visible in\nAdmin Hotline Manager\n(Marked: Call Intake Entry)"]
    APP_RT   --> APP_VIEW["New Custom Hotline\nAppears in Emergency Hotlines Display\nResident Can Tap to Call"]

    ADMIN_VIEW & APP_VIEW --> END_OK(["✅ Emergency Call Intake Hotline\nSuccessfully Added & Available to All Residents"])
