5. Sequence Diagram — Emergency Broadcast Workflow

sequenceDiagram
    autonumber
    actor Admin as Admin Operator
    participant UI as Admin Web Portal
    participant AI as Gemini AI Engine
    participant DB as Supabase PostgreSQL
    participant RT as Realtime Server
    actor Resident as Resident App

    Admin->>UI: Click 'View' on Incident (Pending)
    UI->>DB: Update Status to 'Seen'
    DB-->>UI: Confirm Status Updated

    Admin->>UI: Click 'Generate Summarized AI Alert'
    UI->>AI: Send Prompt (Type, Location, Raw Description)
    AI-->>UI: Return Concise Emergency Alert Text

    Admin->>UI: Review Preview & Click 'Broadcast Now'
    UI->>DB: Insert Alert Record & Mark Incident 'Broadcasted'
    DB-->>UI: Confirm Broadcast Saved

    DB->>RT: Trigger Postgres Change Listener
    RT->>Resident: Push Alert Notification (WebSocket)

6. System Process Flowchart

flowchart TD
    Start([Start: Incident Ingested]) --> SavePending[Save to DB with Status: Pending]
    SavePending --> ShowQueue[Display in Incoming Queue]
    ShowQueue --> AdminView[Admin Clicks View]
    AdminView --> MarkSeen[Update Status: Seen]
    MarkSeen --> Choice{Select Broadcast Path}
    
    Choice -->|AI Route| ClickGen[Click 'Generate Summarized AI Alert']
    ClickGen --> CallAI[Gemini AI Generates Alert Text]
    CallAI --> ClickUse[Click 'Use this message now']
    
    Choice -->|Default Route| ClickDefault[Click 'Use this message too']
    
    ClickUse --> FillForm[Pre-fill Broadcast Alert Form]
    ClickDefault --> FillForm
    
    FillForm --> SubmitBroadcast[Click 'Broadcast Alert']
    SubmitBroadcast --> ShowPreview[Open Preview Modal]
    ShowPreview --> Confirm{Admin Confirms Broadcast}
    
    Confirm -->|Cancel| FillForm
    Confirm -->|Confirm| SaveAlert[Save Alert to DB & Set Status: Broadcasted]
    SaveAlert --> WebSocketPush[Realtime WebSocket Broadcast to Mobile Apps]
    WebSocketPush --> RemoveQueue[Remove Incident from Active Queue]
    RemoveQueue --> End([End Workflow])
